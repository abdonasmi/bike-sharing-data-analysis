# Bike Sharing Data Analysis

## Project Overview

This project analyzes bike-sharing data to understand rental demand and identify patterns based on time, seasons, weekdays, and weather conditions.

## Objectives

- Analyze bike rental demand.
- Identify peak rental hours.
- Compare bike usage across seasons.
- Study weekday and weekend patterns.
- Understand the relationship between weather and bike rentals.
- Compare casual and registered users.

## Dataset

The dataset is obtained from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset).

It contains hourly and daily bike rental records.
